# QF-1 in LTspice

| File | What it simulates |
|---|---|
| `QF1_Main_Filter.cir` | Main filter board: both state-variable sections, the function switch and U4. Default: AC sweep, stepping SELECTIVITY. |
| `QF1_Amp_Supply.cir` | Amp/supply board: bridge rectifier, Sallen-Key driver, BC337/BC327 output into 8 Ω. Default: transient, with output power `.meas`. |
| `QF1_Complete.cir` | Both boards together: receiver audio in, speaker out, powered by the amp board's supply. Generated by `make_complete.py`. |
| `qf1_models.lib` | Op-amp macromodel `QF_OPAMP` (opamp2 pin order: In+ In- V+ V- Out), 1N4001/1N4004, BC337/BC327. |
| `make_asc.py` | Draws `.asc` schematics from the netlists using **your** LTspice symbol files, then checks them with `LTspice -netlist`. |

## Run a netlist
LTspice > File > Open > set the file type to *Netlists (.cir, .net, ...)* > pick a `.cir` > Run. Keep `qf1_models.lib` in the same folder.
Plot `V(out_qf1)` (filter output, board pin 21) or `V(audio_out)` (speaker).

## Front-panel controls (parameters)
| Param | Meaning |
|---|---|
| `FREQ` 0–1 | FREQUENCY pot rotation (0 = CCW = 1.88 kHz, 1 = CW = 181 Hz with 4.7k parts) |
| `SEL` 0–1 | SELECTIVITY rotation (0 = flat, 1 = narrowest, about 22 Hz cascaded) |
| `MODE` | 1 = PK, 2 = NTCH, 3 = LP |
| `LOGPOT` | 0 = linear pots, 1 = audio taper |
| `OPGBW`, `OPSR` | Op-amp speed: 3Meg/13Meg = TL072 (rebuild); 1Meg/0.5Meg = µA747/741 (original) |
| `RT`, `RQ`, `RT8` | The "chosen on test" resistors (R3/R5/R10/R11, R4/R9, R8); default 4.7k |
| `VACRMS`, `RLOAD`, `MAINS` | Amp board: AC input (V rms), speaker impedance, mains frequency |

Use `.step param ...` (examples are commented in each file) to sweep any of these.

## Checked in ngspice (default parts)
- PK: f₀ 181 Hz to 1.88 kHz; at full selectivity, about 22–24 Hz −3 dB bandwidth and +28 to +30 dB gain.
- NTCH: 46–65 dB deep. LP: +13 dB passband, falling 40 dB within 1.25 octaves.
- Amp: B+ 15.1 V unloaded (12 VAC in), clips at about 3.9 V peak, or about 0.95 W into 8 Ω.
- Complete unit, peak set to 1 kHz: +22.6 dB at 1 kHz, about −18 dB relative at ±100 Hz, about −40 dB at 700 Hz and 1.4 kHz.

## Schematics (.asc)
```
python make_asc.py            # finds LTspice and its lib/sym folder automatically
python make_asc.py --sym "%LOCALAPPDATA%\LTspice\lib\sym" --exe "C:\Program Files\ADI\LTspice\LTspice.exe"
```
Parts are grouped by stage, with every pin connected to a wire stub and a net label. The script then netlists each `.asc` with LTspice and reports whether every connection matches the `.cir`.
